{\large\bfseries Project Proposal: A Compiler from StragglAR Schedules to NCCL Send/Receive Programs}\\[2pt]
Team 31 (Chesterjesters): Wyatt Sell, David Valarezo, Nathnael Tesfaw, Aneesh Naresh\\
Advisor: Arjun Devraj \quad$\cdot$\quad Compute: 2 Perlmutter nodes (8$\times$A100, NCCL over Slingshot)
\end{center}

\textbf{Goal.} Build a compiler that reads StragglAR's synthesized schedule (rounds of \emph{StragglerMatching}, \emph{OneWayMatching}, and \emph{TwoWayMatching} transfers) and generates a C++/CUDA program of grouped \texttt{ncclSend}/\texttt{ncclRecv} calls with local reductions, one process per GPU. We aim to achieve a program that runs without deadlock on 8 GPUs across two nodes, gives the same output as \texttt{ncclAllReduce}, and on 4 GPUs (one node) finishes faster than \texttt{ncclAllReduce} when the same straggler delay is injected into both. Beating it on 8 GPUs across two nodes is a stretch goal, since StragglAR assumes equal-speed links between all GPUs.
